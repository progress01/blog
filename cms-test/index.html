上稿工具測試包

不用真的後台，先用模擬後台把「圖片路徑自動回填」跑一遍。約 3 分鐘。

開收件台開模擬後台開上稿工作台

測試一：圖片路徑回填（最重要）

  1. 按上面的「開收件台」。
  2. 按這個鈕：
    到收件台頁面任何地方按 Ctrl+V。會出現「【測試】講師頁｜測試機」，裡面有 1 張新圖片（meeting-photo.jpg）。
  3. 按「開模擬後台」。這頁假裝圖片已經上傳好了，內嵌檔案清單裡有路徑。
  4. 在模擬後台按 Ctrl+A（全選），再按 Ctrl+C（複製）。
  5. 回到收件台，點「② 回填圖片路徑」下面的框，按 Ctrl+V。

成功的樣子：上方訊息寫「在貼上的內容裡找到 4 個圖片路徑，配對了 3 張」，三張圖旁邊都打勾。「③ 貼上原始碼」裡的三個圖片路徑變成 /img/EMA/…。

第 4 張（海報.webp）在「相關圖片」裡，這次原始碼沒用到，會自動略過。

測試二：在真的後台（VDI）

  1. 把收件台帶進 VDI：工作台右上「完整功能 → 上稿到環境 → 複製收件台」，或直接用這個測試包的收件台頁面。VDI 裡開記事本貼上，另存成 收件台.html（編碼 UTF-8），用瀏覽器打開。
  2. 把「測試包裹」貼進 VDI 的收件台（同測試一的第 2 步）。
  3. 在測試機任一頁的「內嵌檔案」上傳一張圖，檔名改成 meeting-photo.jpg。
  4. 在那個編輯頁按 Ctrl+A、Ctrl+C，回收件台的回填框按 Ctrl+V。

看訊息「找到幾個圖片路徑」：只要 meeting-photo.jpg 打勾就成功。不要按儲存，測完把那張測試圖刪掉即可。找不到的話，把貼上後的畫面截圖回報。

測試三：工作台的簡單畫面

  1. 按「開上稿工作台」，第一次會出現「新增頁面」。
  2. 頁面名稱填 COP29 講師（測試），網站填 氣候署官網，把下面的原始碼貼進「CKEditor 原始碼」，按「存起來」。
  3. 在「要改什麼」打 童子賢職稱改成召集人，按「找出要改的地方」，畫面上會標出黃色。
  4. 按「複製給 AI 的指令」，貼到 ChatGPT，把回覆貼回來按「檢查」。
COP29 開幕活動講師區塊，取自前台公開頁面

想讓畫面跟前台一樣：在「新增頁面」展開「讓畫面跟前台一樣」，網址填 https://www.cca.gov.tw，再到前台 COP29 開幕活動頁 按 Ctrl+U 全選複製貼上。
