# blog
https://progress01.github.io/blog/

## 工具
- [Blog Content Builder](https://progress01.github.io/blog/)：部落格文章模板與草稿（Google 登入、Firebase 備份）
- [多環境上稿助手](https://progress01.github.io/blog/cms-helper.html)：一份稿源產出公司機／測試機／正式機的 CKEditor HTML，記錄各環境上稿版本、差異比對、圖片路徑切換、AI 提示詞協作。不需登入、不連網，資料只存在本機瀏覽器；也可以下載 `cms-helper.html` 直接離線開啟。
