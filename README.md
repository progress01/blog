# blog
https://progress01.github.io/blog/

## 工具
- [Blog Content Builder](https://progress01.github.io/blog/)：部落格文章模板與草稿（Google 登入、Firebase 備份）
- [上稿工作台](https://progress01.github.io/blog/cms-desk.html)：以 CMS 單元為單位管理上稿。Excel 版本自動比對、AI 提示詞往返與自動檢查（標籤、無障礙、圖片路徑、新文字是否有來源）、原始碼版本、圖片最佳化，並依環境（公司機／測試機／正式機）打包上稿包。不需登入，資料只存在本機瀏覽器。
- [上稿收件台](https://progress01.github.io/blog/cms-receiver.html)：在 VDI 裡還原上稿包（原始碼、圖片、節點設定清單），也可接收物流箱 V5 包裹。約 15 KB，可用記事本另存成 .html 帶進離線環境。工作台的「上稿到環境」頁也能直接複製。
- [多環境上稿助手（舊版）](https://progress01.github.io/blog/cms-helper.html)：以模板變數為主的前一版，保留參考。
